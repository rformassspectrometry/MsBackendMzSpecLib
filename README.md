# mzSpecLib file format support for R and `Spectra`

[![Project Status: WIP – Initial development is in progress, but there has not yet been a stable, usable release suitable for the public.](https://www.repostatus.org/badges/latest/wip.svg)](https://www.repostatus.org/#wip)
[![codecov](https://codecov.io/gh/rformassspectrometry/MsBackendMzSpecLib/graph/badge.svg?token=gn0M7XcrWs)](https://codecov.io/gh/rformassspectrometry/MsBackendMzSpecLib)

This repository/R package provides support to read and write HUPO-PSI
[mzSpecLib](https://www.psidev.info/mzspeclib) files and implements a *backend*
for direct integration and import of the data as
[Spectra](https://github.com/RforMassSpectrometry/Spectra) objects.

# Installation

The package can be installed with

```r
install.packages("BiocManager")
BiocManager::install("RforMassSpectrometry/MsBackendMzSpecLib")
```
